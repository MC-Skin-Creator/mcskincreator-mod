First public release.

- Skin editor inside the game: library, player model scene, layer stack with
  inspector, undo and redo.
- Starter models and outfits, with the origin of every element one click away.
- Saved skins kept on the MC Skin Creator server.
- Export of the composed skin sheet or the front view.
- Apply the skin to your Minecraft account and wear it immediately, no restart.
- English, French and Spanish.
- Supports Minecraft 1.21.11 and 26.2 (26.2 not yet run in a real game).
